# 方法说明：sci-pdf-parse 的解析原理

本文件是 SKILL.md 的技术附录，供 Agent 在标准流程失效时查阅细节，也供人工评审复核方法。

## 1. 探测分类（pdf_probe.py）

- `pdfinfo` 读取页数、页面尺寸、加密标志。
- 逐页运行 `pdftotext` 统计非空白字符数：<50 字符/页视为无文字层。
- 分类规则：全部页有文字层 → `digital`；全部页无文字层 → `scanned`；部分有 → `mixed`；`pdfinfo` 报加密且无文字 → `encrypted`。

## 2. 几何提取（pdf_extract.py）

### 2.1 词盒获取

`pdftotext -bbox-layout` 输出 XHTML，含每个 word/line/block 的 `xMin,yMin,xMax,yMax`（单位 pt，页面坐标系，原点在左上）。这是全部版面判断的事实来源，不依赖任何"看起来对"的纯文本输出。无 block 层级的 poppler 版本自动回退为按 y 中心把词聚成行。输出先经 XML 净化（控制字符、裸 `&`），非 ASCII 路径自动走临时目录重试。

### 2.2 页眉页脚剔除

- 候选：块的底边在页高 8% 以内，或顶边在页高 93% 以外；纯页码块放宽到页高 90% 以外。
- 剔除条件（满足其一）：归一化文本在 ≥40% 页面（且 ≥3 页）重复出现；或文本是独立页码（`[-0-9ivxlcdm.–—]{1,12}`）。
- 被剔除的块全部记录在 `pages.json.dropped_headers_footers`，可人工复核；误删时用 `--keep-headers` 重跑。

### 2.3 分栏检测

两步判定，兼顾双栏页中的通栏元素与单栏页的误检：

1. **候选**：先排除宽度 >55% 页宽的行（标题、通栏表格、通栏摘要——它们合法穿越任何栏间空白，不应参与投票）；在页宽 30%–70% 的中央带内寻找被 ≤max(3, 4%) 行穿越的最宽竖直空白条，宽度 ≥1.5% 页宽方成为候选。若 >70% 的行都是宽行，直接判为单栏。
2. **验证**：用**全部行**复核候选中线——真正的栏间空白只有通栏元素穿越（≤25% 行）；单栏页的正文在每个 x 处都有大量穿越，据此否决伪 gutter。

找不到有效 gutter 则按单栏（y 坐标）排序。

### 2.4 阅读顺序（带状排序）

- 跨越 gutter 且宽度 >62% 页宽的块视为通栏块（标题、摘要、通栏图表）。
- 通栏块按纵坐标把页面切成水平带；每个带内先输出左栏块（自上而下），再输出右栏块（自上而下）。
- 跨页续接：上一页末尾与下一页开头是同一逻辑段落时，按块顺序自然衔接；断字合并见 2.5。若上一页以连字符结尾而下一页开头为小写，属跨页断字，可人工合并并在 `change_log` 记录。

### 2.5 段落与断字

块内各行按空格连接成行内文本；行尾为 `-` 且下一行首字母小写时去连字符直接拼接（英文断字）。中文文本不做断字处理，直接连接。

### 2.6 块类型启发式

| kind | 判定 |
|---|---|
| heading | `1.`、`2.3` 等编号开头，≤2 行，并通过词法护栏：≤8 词、不以句号结尾、不含 `(` / `http` / `%`、编号后首字母大写或 CJK（排除图表刻度、脚注、URL）；或整行等于 references/参考文献 |
| abstract | 以 abstract/摘要开头 |
| caption | 以 Figure/Fig./Table/Algorithm + 编号开头 |
| equation | ≤4 行且行尾有 `(编号)` |
| reference | 位于 references 标题之后 |
| table-candidate | ≥3 行、多数行含 ≥2 个 >14pt 的内部空隙 |
| paragraph | 其余 |

启发式可能误判（尤其 equation 与 table-candidate），因此所有引用必须回到块文本与页面渲染图核对。

**标题的两个补救机制**（poppler 的分块常与逻辑标题不一致）：

- 标题与正文并入同一块：块首行满足编号模式与词法护栏时拆出独立标题块。
- 编号与标题分成两个相邻单行块（NeurIPS 风格：`1` + `Introduction`）：满足同样护栏时合并为标题。

## 3. 表格还原（pdf_tables.py）

页面级检测（不依赖 poppler 分块，单元格常被拆成小碎块）：

1. 全页词盒按纵中心（容差 4pt）聚成行。
2. 表区域 = ≥3 个连续行共享一致的大空隙（>14pt）列界；生长期共识阈值 0.4、最终验证 0.6，允许表头行只有 1 个空隙（角单元格为空的情况）。
3. 双栏页做**双通道**：先按栏中线分左右两列各自检测（栏内表），再做全页检测（通栏表）；通栏候选若 >50% 词与栏内区域重叠、或 ≥40% 行含 ≥6 词的长单元格（正文污染）、或宽度 ≤55% 页宽，则丢弃。无题注且正文污染率 ≥40% 的区域一律丢弃。
4. 列界细化：密集数值表的列间距（≈4.5pt）远小于词距阈值，区域内部用 `max(4pt, 1.4×页面词距中位数)` 重新聚类列界，再按词中心分配单元格，输出 Markdown 与 JSON 网格。
5. 题注关联：区域上下 60pt 内的 `Table N` 题注自动附加。

已知边界：合并单元格、多层表头可能错位；图内文字（网络结构图、坐标轴刻度）可能被误判为表 → 输出固定标 `confidence=heuristic`，引用前必须渲染核对。跨页续表：两页各自提取后按表头一致性人工合并，`change_log` 记录合并依据。

## 4. 渲染核对

```bash
pdftoppm -r 150 -f <p> -l <p> -png input.pdf out-prefix
```

核对清单：数字与单位逐字一致；上下标位置正确；表格行列归属正确；题注编号与图表对应。发现不一致时以图像为准修正块文本，并在 `change_log` 记录。

## 5. 扫描件 OCR 路线

```bash
pdftoppm -r 300 -f <p> -l <p> -png input.pdf work/page
tesseract work/page-<p>.png stdout -l eng+chi_sim --psm 3
```

- 低分辨率扫描件用 `-r 400`；倾斜件先 `--psm 0` 估计方向再旋转。
- 双栏扫描件：`tesseract --psm 1`（自动版面分析含栏检测），或先按图像中线裁开两半分别 OCR。
- OCR 文本一律标 `kind=ocr-text` 并在 `uncertainty` 记录；公式与表格区域 OCR 不可靠，标 `unreadable-region` 并附页面渲染图路径。
- 无 tesseract 时：不编造文字，相关页标 `unreadable-region`，`status=partial`。

## 6. 公式与特殊字符保真

- `pdftotext` 对多数嵌入字体能给出正确 Unicode（α、β、±、≤、上标 ² 等）。
- 私用区字符（U+E000–U+F8FF）= 字体缺 ToUnicode 映射，**其字形信息不在文本层**。处置：渲染该页截图判读；判读不出时按公式编号列入 `uncertainty`，禁止用形近字符顶替。
- 下标/上标在 bbox 中表现为字号更小、纵向偏移的独立词；`equation` 块保留原始换行以维持上下结构线索。
- 常见映射核对表（提取结果 ↔ 原文截图）：α β γ δ ε θ λ μ π σ φ ω Γ Δ Θ Λ Σ Φ Ω，± × ÷ ≤ ≥ ≠ ≈ ∞ ∂ ∇ ∈ ∉ ⊂ ∪ ∩ → ⇒，⁰¹²³ⁿ ₀₁₂。
